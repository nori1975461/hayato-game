# れんしゅうじょう（本編とは別のテストモード）

実プレイFB（2026-08-23）:
> 連続撃破の体感を 0キーで「標準 / 全開 / ひかえめ / 切」を確かめたいが、通常プレイだと
> 敵の攻撃が激しくて確認に集中できない。確認するためだけのテストモードを本編とは別に作って。
>
> ①紫の輪が出たら掴めない ②ボンバは溜められない が、プレイ中はよくわからない。
> それらしいのはあったが「うかつに掴みにいけない」という感覚はなかった。まず事実を確認したい。

## 入り方

- タイトルで **T キー**（`SPACE` はふつうのゲーム）
- 検証用に `?practice=1` でも入れる（この場合はふつうの開始でもれんしゅうじょうへ行く）

## 操作

| キー | はたらき |
|---|---|
| 1 / 2 / 3 / 4 | コースを変える（同じ数字をもう一度押すと出し直し） |
| N | 出し直す |
| 0 | 一気撃破の音を切り替える（①のコースで使う） |
| Z / X / C | ④のコースで 分離／再合体／体力まんたん へ即ジャンプ |
| Q | タイトルへ戻る |

## れんしゅうじょうで止めているもの

**確かめたい仕組み以外は全部止める**。ただし**仕組みそのものは本編の実装をそのまま動かす**
（ここで作り直すと「練習では起きるのに本編では起きない」を見逃す。R25で断末魔が9%しか
完走していなかったのと同じ罠）。

- 敵の湧き・モビット捕獲・王冠 … 止める
- ボス … ①②③では止める。**④のコースだけ回す**（`practice.wantBoss()`）
- 敵のふつうの攻撃 … 止める（**断末魔だけは本編どおり起こす**＝確かめたい仕組みそのもの）
- なかまの攻撃 … 止める（`damageMult = 0`）。撃破が自分の投げだけになるので音を聴き比べられる
- 主人公 … 死なない（HPは1で止まる）。**音・揺れ・赤フラッシュ・押し返しはそのまま**残すので、
  「よけたか／くらったか」は体で分かる

## コース

### ① いっきに たおす おと
動かない敵の壁（チビット4×4）と、足元によろけた弾（HPの高いガレオン）。
毎回まったく同じ並びで出るので、**0キーで音だけを変えて同じ場面を聴き比べられる**。
画面下に「さいご：N体／さいこう：N体」を出す。

★R29W2：0キーの4つは **たいこ／ばくは／きらきら／切**。以前は間隔(52/44/64ms)と絵しか
違わず、鳴らす音は4つとも同一だった（実プレイFB「ほぼ差がなかった」は正しかった）。
いまは音色そのものが別（打楽器／炸裂ノイズ／金属の音階）。詳細は
[r29w2_practice_feedback.md](r29w2_practice_feedback.md)。

実測：1回の投げで **6〜9体**を一度に倒せる（スローモーションが入る8体の帯まで届く）。
本編では8体以上は16秒に1回しか来ないので、ここでは意図的に届かせている。

### ② むらさきの わ が でたら つかめない
断末魔つきの敵を1体だけ置く。**敵の頭の上に「つかめない！／つかめる」を常時表示**する。
これがこのコースの本体で、「うかつに掴みにいけない」の正体を目で確認できる。
画面下に「とんできた／よけた／くらった／つかんだ／はじかれた」を数える。

実測（本編と同じ判定関数で確認）：紫の輪が出ている間は
`つかめる=false`・`nearestEnemy` が拾わない → 予告が終わると `つかめる=true` に変わる。

★R29W2：**手を出すと弾かれて0.3秒しびれる**ようになった（ダメージは0）。
以前は候補から外して突きに落ちるだけで、失敗が体験として存在しなかった。
よろけの輪も予告中は紫になる（以前は「掴める」の青白のままで矛盾していた）。
的の位置も `px+120`→`px+70` に変更（掴める距離は78pxなので、旧位置では窓の1/3を歩いて消費していた）。

### ③ ボンバは ためられない
ボンバを1体だけ置く。掴むと手の中で赤く点滅し、ビープが速くなり、**溜め続けると手の中で爆発**する。
持っている間は残り時間を数字でも出す（耳と目だけだと分からない、というFBへの対処）。
画面下に「てのなかで ばくはつ／ばくだんで なげた／ばくはつ させた」を数える。

★R29W2：**導火線が残るうちに投げ切ると「ばくだんの たま」になる**（実プレイFBの提案）。
敵に当たると爆発して半径140pxを面で巻き込み、貫通せずそこで終わる。
＝「急いで投げる」理由が罰（手の中で爆発）だけでなく報酬にもなった。

⚠️ このコースだけ、**地面に落ちている間は導火線を止めている**。本編では拾うまでの1秒で
自分から爆発してしまい、手の中で燃えるところまで辿り着けないことが多いため
（実測：導火線の発火0回／掴まれて消滅37%）。止めているのは**用意の仕方だけ**で、
手に持ってからの処理は本編そのまま。

### ④ マオウレクスと たたかう

最終ボスだけを名指しで出す（`boss.practiceSpawn('maou')`）。ここでも**戦闘は本編の実装そのまま**で、
このコースがやっているのは「出す・見える位置に置く・節目へジャンプさせる・名札を出す」だけ。

| キー | 何が起きるか |
|---|---|
| Z | 体力49%へ。次のフレームで**分離**が起きる（判定は本編の `update` がやる） |
| X | 体力32%へ。**再合体してメタリックパープル**になる |
| C | 体力まんたん。何度でも節目を見返せる |

- **上半身と下半身に名札を出す**。「うえはんしん ← コアを ねらえ」／「したはんしん（きかない）」。
  R30の申し送り「分離した下半身が下半身だと読めるか」をここで確かめてもらうのが狙い。
  ⚠️ 名札は縦にずらす（両方とも頭の上に出すと分離直後は重なって読めない。実測で踏んだ）
- 弾（そうこうへん）は本編どおり**ボスの予告を突きで割って**出す。ここを簡単にすると
  ボス戦の手順そのものが練習できなくなる
- 画面下に「ぶんりつ／がったい／コア／はじかれ／レーザー（あたり/発射）」を数える。
  コアに通ったか弾かれたかは本編の `weakGate` の**結果を数えるだけ**（計測器が同じ条件式を持たない）
- 撃破してもエンディングへ飛ばず、1.6秒後に出し直す

⚠️ 本編は 350px 離れた位置にボスが出る。練習場は「まず見つける」ところから始めさせないので
`px + 250` へ置き直している。既定の位置だと**出た瞬間から画面外**で、名札もカットシーンも見えなかった。

⚠️ れんしゅうじょうでは HUD の開発用表示（FPS/敵/弾/seed）を消した。下段の帯と左下で重なって
成績が読めなくなっていた。

## 検証

`node vortex/scratchpad/cdp-r30w2-practice-maou.mjs` で④を通す（EXCEPTIONS=0）。
`node vortex/scratchpad/cdp-practice.mjs 42 60 nogod` で①②③を通す（EXCEPTIONS=0）。
- ①で実際に掴んで壁へ投げ、一気撃破が鳴った体数まで確認する
- ②は本編と同じ条件式（`!(e.throe && e.guardT > 0)`）と `nearestEnemy` の両方で実測する
- ③は掴んだまま2秒持ち続けて、手の中で爆発することを確認する

### 実装で踏んだ穴

- **カウンタを「今の値 − 開始時の値」で出すと、出し直すたびに基準が上書きされて常に0に戻る**。
  手から消えた瞬間の遷移で1回ずつ数える形に直した
- 練習では 1〜3 をコース切替に使うので、本編の「打撃感プリセット（1〜4）」と衝突する。
  れんしゅうじょう中はそちらを無効にした
- `enterStagger` は中で `startDeathThroe` を呼ぶので、①のコースでも紫の輪が出てしまっていた。
  `practice.wantThroe()` で①だけ断末魔を起こさないようにした
- ★④を足すとき、ボスは**時間では出せない**ことが分かった（`ti` は撃破でしか進まないので
  `elapsed` を進めても最初の1体しか出ない）。名指しで出す口 `practiceSpawn(bossId)` を
  boss.js に足し、逆に `practiceMode` では時間による自動出現を止めた（放っておくと58秒後に
  コロタマが出てくる）
- ★コースを切り替えるときは**ボスを先に片付ける**。下半身も `run.enemies` に載っているので、
  先に `active` を落とすと boss.js 側の参照だけが残って幽霊になる
