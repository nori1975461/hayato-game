# R26 — 「王冠も断末魔も意識できなかった」の原因と直し

実プレイFB（2026-08-23・マオウレクス撃破まで到達）：

> 王冠と断末魔は全く意識できなかった。特に断末魔は「うかつに捕獲しにいけない。その分、
> 捕獲したときの報酬が大きい」という設計を楽しみにしていたのだが。手元で着火×爆発もみれなかった。
> ずっしりを投げたときの気持ちよさもあまり感じれなかった。重量のある弾を取得したという重みが
> そもそも、プレイ中に感じれなかった。

---

## 結論：見えなかったのではなく、**起きていなかった**

R25で私が報告した「断末魔 8.4回/分」は**予告が始まった数**で、体験された数ではなかった。
発火まで追う計測器（`cdp-r26-percept.mjs`）を作って測り直した。

### 実測（実装前・seed=42・200秒・通常モード）

| 断末魔の顛末 | 回数 |
|---|---|
| 掴まれて消滅 | **19回（83%）** |
| 割られて消滅 | 2回（9%） |
| **実際に発火** | **2回（9%）＝ 0.6回/分** |

| ボンバの導火線の顛末 | 回数 |
|---|---|
| 掴まれて消滅 | 9回（53%） |
| 割られて消滅 | 8回（47%） |
| **実際に発火** | **0回（0%）** |

原因は3つとも実装を読めば分かるものだった：

1. **よろけてから掴むまで 中央値0.23秒**。予告0.5秒は原理的に完走しない
2. 予告中に殴ると既存の**カウンター判定**が入って `atkState` が `ready` に戻る（停止）
3. よろけ敵は殴れば割れる＝撃破。予告ごと消える

### 王冠も同じ構造だった

| 王冠18体の生存 | 値 |
|---|---|
| 生存の中央値 | **1.2秒** |
| 2秒未満で消えた | **13体（72%）** |
| 生まれた位置の主人公からの距離 | 中央値158px |
| 弾にされた／割られた | 8体 ／ **10体** |

王冠は「近くで3体倒れた場所」＝**自分のキル圏のど真ん中**に生まれる。気づく時間が物理的に無い。

### 「ずっしりの重み」も測れば当然だった

| 弾を持っている時間 | 平均 |
|---|---|
| かるい | 0.53s |
| おもい | 0.53s |
| **ずっしり** | **0.52s** |

格で全く変わらない。**「持っている間」に置いた演出（移動-12%）は、0.5秒では絶対に伝わらない。**

## 直し方

### ① 断末魔は「中断できない一手」にする

頻度ではなく**中断されないこと**が問題だったので、そこだけ直す。

- 予告中（0.8秒）の敵は **掴めない・割れない・殴っても止まらない**
- 見た目を専用色（紫）に。輪は脈打ち、本体も紫に点滅し、「まだ しんでない！」と出る
- ＝ 「よろけさせた → 紫の輪が出る → 一発避ける → それから捕獲する」というリズム

⚠️ **爆風はそのままでは避けられない。** 初回検証で回避率**0%**、ボットが22秒で死んだ。
主人公は 148px/s なので0.8秒で118pxしか動けず、ガレオンの爆風120は出られない。
断末魔のときだけ **爆風0.55倍（120→66）・ダメージ0.45倍（18→8）** にした。
危険半径は 66+7=73px なので、密着からでも 0.49秒で出られる（31pxの余裕）。

⚠️ **溜めている最中は避けられない**（0.5倍速＝74px/s で0.99秒かかる）。これは意図的に残す。
「溜めを中断して逃げるか、被弾覚悟で溜め切るか」という判断が毎回生まれる。

### ② 王冠は「生まれた瞬間」を作る

キル圏の内側に生まれること自体は変えない（キルが引き金だから必ず発火する、というR25の要）。
代わりに、生まれた瞬間に**必ず1秒立っていられる**ようにした。

- 一瞬止まる（0.10秒）＋ 画面が揺れる
- **周囲96pxの仲間を吹き飛ばす**＝混戦から王冠だけが浮き上がる
- **0.6秒の無敵**（金の輪郭が脈打つ）＝ 気づく時間を必ず作る
- 頭上の金の星を 1.5 → **2.3倍**、画面上部にアナウンス、画面外なら追尾の矢印
- HPは「削られた状態から2.5倍」ではなく**全快させてから2.5倍**
- 頻度は7秒→9秒に1回へ下げ、**45秒より前には出さない**（序盤にHP2.5倍は過剰。ボットが死んだ）

### ③ ずっしりの重みは「掴んだ瞬間」に全部乗せる

持っている窓が0.53秒しかない以上、そこに置いた演出は届かない。山を掴みへ移した。

| | ずっしり | ばくだん級 |
|---|---|---|
| 掴んだ瞬間に止まる | 0.10秒 | 0.16秒 |
| 画面揺れ | 7px | 14px |
| 足元の波紋 | 1枚 | 2枚（時間差） |
| 弾の大きさ | ×1.45 | ×1.85 |
| 持っている間の移動 | ×0.78 | ×0.66 |

### ④ ボンバの導火線を「必ず見える」ようにする

3.0秒では実測**発火0回**。掴むまで0.29秒＋持つ時間0.53秒＝手を離れるのが速すぎた。

- 導火線 3.0秒 → **1.0秒**、さらにボンバにも0.35秒の掴み禁止を掛ける
- ＝ 掴んだ時点の残りが**溜め切り0.85秒を必ず下回る**。「ボンバだけは溜められない」
- 手の中の弾が赤く明滅する（速さが残り時間）＋ ビープが加速する

### ⑤ マグマンの間隔を平均34秒 → 54秒

実プレイFB「ボスの体力が大きいので特殊弾はありがたいが、少し多い」。
珍しさは間隔でしか作れないので、湧く位置・矢印・アナウンスは触らず間隔だけ広げた。

---

## ⚠️ ボットでは「避けた回数」を測れない

ボットはよろけ敵へ突っ込むAIなので、紫の輪が出ても離れない（実測の回避率10%）。
**②の緊張感はボットでは測れない**という既知の制約がそのまま出ている。

そこで判定を2つに分けた：

1. **避けられるかは幾何で保証する**（危険半径73px ÷ 主人公148px/s ＝ 0.49秒 < 予告0.8秒）
2. **ワーストケース（回避率0%）でも死なないこと**をボットで確認する

## 実測（R26後）

### ① 断末魔は「体験される」ようになった

| | 実装前 | R26後 |
|---|---|---|
| 予告の回数 | 23回 | 44回 |
| **実際に発火** | **2回（9%）** | **37回（84%）** |
| 発火の頻度 | 0.6回/分 | **9.2回/分** |
| 掴みで中断 | 19回（83%） | **0回** |

⚠️ 途中、掴み禁止0.7秒に対して予告0.8秒と**0.1秒の穴**があり、そこだけで発火が84%→51%に落ちた。
`test-core` に `guardSec >= telegraphSec` を固定して二度と開かないようにした。

### ② ボンバの導火線が動くようになった

| | 実装前 | R26後 |
|---|---|---|
| 手の中で爆発 | **0回** | 3回 |
| 床で自爆（導火線が完走） | 0回 | 6回 |

### ③ 王冠は認識できる帯に入った

| | 実装前 | R26後 |
|---|---|---|
| 生存の中央値 | 1.2秒 | 1.8〜2.2秒 |
| 2秒未満で消えた | **72%** | 31〜56% |
| 弾にされた割合 | 44% | 44〜69% |

### ④ 難度の増分は「差分」で測った

ボットは死ぬ時刻がランごとに大きくぶれるので（同じseedで87秒と193秒）、生存時間では判定できない。
**同じビルド・同じseedで、`startDeathThroe` と `maybeCrown` だけを止めた対照ラン**と比べた。

| seed=7 / 242秒 / 無敵 | 被弾レート |
|---|---|
| R26機能 **OFF**（対照） | 4.04 /秒 |
| R26機能 **ON** | **4.86 /秒** |
| **差分** | **+20.3%** |

しかもこれは**ボット＝回避率26%のワーストケース**での数字。避ければ断末魔のぶんは0になる。
（対照ランでは王冠0体・断末魔0回・ずっしり0投を確認済み＝止められていることの裏取り）

### ⑤ 「見える位置に描かれるか」を等倍のスクリーンショットで確認した

- `r26-throe-full.png` … 紫の輪が画面幅の23%で描かれ、赤い通常予告と混ざらない
- `r26-crown-full.png` … 「おうかん！ たおして たまにしろ！」の告知と追尾ラベルが等倍で読める
- 予告が出ている**その瞬間**に `dealDamage` と掴み判定を呼んで、`割れない=true` `掴めない=true` を実測

検証：
- `node vortex/scratchpad/cdp-r26-percept.mjs [seed] [秒] [god|nogod] [off]` … 最後に `off` を付けると対照ラン
- `node vortex/scratchpad/cdp-r26-shot.mjs` … 王冠と断末魔を強制発動して等倍＋拡大で撮る
