## 1. ①の正体：当たり判定とダメージ判定が別々の円だった

**息子さんの体感は正しかった。** バランスの問題ではなく、2つのファイルが違う円を見ていた実バグ。

| | 使っていた円 | 半径 |
|---|---|---|
| `billiard.js` の当たり判定 | 玉の半径 ＋ コア半径 | 28 + 27 = **55px** |
| `boss.js` の `weakGate`（ダメージ判定） | コア半径だけ | **27px** |

この間（27〜55px）に落ちた命中は、`hitOne` → `bossImpact` が

- ヒットストップ（`freezeT`）
- 画面シェイク 170ms
- ズームパンチ
- 衝撃波リング2枚
- 光条バースト＋粒子18個
- 金属着弾音＋`bigBoom`

を**全部出したうえで、ダメージ数字に「0」を表示して砕ける**。つまり画面上は完全に当たって見える。
「コアにあてているのに減らない」はそのまま起きていたことの説明になっている。

### いちばん悪いのは逆転していたこと

玉の半径は `max(20, 獲物の半径) × (0.85 + 0.15 × ballMul)`。`ballMul` は投げの段位で **1.9 → 3.8** と増える
（`balance.js` の tiers）。つまり**強くなるほど玉が大きくなり、当たり判定は広がるのに、ダメージ判定は
27px のまま**。上手くなるほど「当たったのに0」の割合が上がる。

| 段位 | 玉の半径 | 当たり判定 | 通る面積比 |
|---|---|---|---|
| なげる（ballMul 1.9） | 22.7px | 49.7px | 27²/49.7² = **30%** |
| ボルテックスなげ（3.8） | 28.4px | 55.4px | 27²/55.4² = **24%** |

### 直し方

`weakGate` の判定円に飛び道具の半径を足すだけ。範囲攻撃の `at.r`（コア倍率2.4を落とす側）とは
役割が違うので、**別フィールド `at.hitR`** にした。必殺技の「範囲攻撃はコア倍率なし」は壊していない。

```js
const rr = w.r + (at.r || at.hitR || 0);
```

## 2. ①の第2の原因：分離した下半身が玉を食べていた

R30 で足した下半身（HPを持たない砲台）にも**同じ形**の問題があった。下半身はコアを持たないので
`weakPoint` が null を返し、通常の当たり判定に落ちる → `bossImpact` が全部の演出を出して「0」を表示 →
玉は消費される。**分離中は下半身に当たった投げが丸ごと消えていた**（実測16秒で39回）。

上半身の装甲と同じ扱いにした：**「カキン！」だけ返して弾は通す**（奥のコアへ届く）。
「下半身は倒せない」という仕様は変えていない。変えたのは「倒せないうえに弾を食う」をやめたこと。

## 3. ②BGM：荘厳さの材料には触らず、暗さの原因3つだけを直す

荘厳さを作っている材料（オルガンの持続和音・ティンパニ・教会の鐘・全音符主体・ビートを置かない）は
**1つも触っていない**。暗さの原因になっていた3点だけを直した。

| 暗さの原因 | 直し方 |
|---|---|
| (1) 和音が全部マイナー（Am-F-G-E）で長三和音が0個 | 4→8小節に伸ばし、3小節目に **C**、8小節目に **A メジャー**（ピカルディ終止） |
| (2) 主題がオクターブ**下**しか重なっておらず輝く高域が無い | オクターブ上（と4倍音）を重ねる |
| (3) 鐘（唯一の明るい声部）が2小節に1回 | **毎小節**にし、長三和音の小節だけ基音を和音の第3音まで上げる |

**ピカルディ終止**＝短調の曲を最後の和音だけ長三和音で閉じるバロック教会音楽の定石。
「荘厳さを崩さずに光だけ入れる」という注文にそのまま対応する語法なので、これを軸にした。
テンポも 76→84BPM（battle 150 / boss 172 の半分程度＝重さは保つ）。

## 4. ③ミサイル：本物の地対空ミサイルの音響特徴に合わせる

調べた実物（S-400 等のコールドローンチ式）の特徴と、それが旧実装に無かったもの:

| 実物の特徴 | 旧実装 | R31 |
|---|---|---|
| ① 第一音は火の轟音ではなく**高圧ガスの破裂**（発射管から押し出す） | 無し | `samLaunch` の低い「ボスンッ」 |
| ② 空中でモーター点火＝**耳を裂く鋭いクラック** | 無し | 0.07秒後の鋭いノイズ＋高域スイープ |
| ③ 固体燃料は数秒で燃え尽き、**持続する轟音にはならない** | ― | 噴射ブラストを0.30秒で切る |
| ④ 飛翔中に聞こえるのは主に**大気を切り裂く風** | 噴射轟音が主役 | `samFly` は風のノイズが主役＋超音速のクラックル |

速度は 340→**480px/秒**。旋回上限は 88°/秒 のまま据え置いたので、旋回半径は
340/1.536≒221px → 480/1.536≒**313px** と**逆に広がる**。速くて怖いが、横へ切れば前より抜けやすい。
`lifeSec` は 3.2→2.4（射程 1088→1152px でほぼ同じ。伸ばすと画面外を延々飛ぶ）。

**「主人公に当たった先の爆発」が本題だった。** 旧実装の直撃処理は `Sound.sfx('hit')` と粒子8個だけで、
爆発は起きていなかった。低音ドロップ＋爆風＋破片の `samBoom`、二重の衝撃波、白フラッシュ0.30、
0.05秒のヒットストップを足した。7発が同時に爆ぜると音が潰れて1発ぶんに聞こえるので、爆発音は間引く。

飛来音は**飛んでいるあいだ鳴らし続ける**。速くしたぶん、発射時の1回だけでは鳴り終わる前に着弾して
「迫ってくる」怖さが出ない。近いほど音程を上げ、間隔も詰める（ドップラー）。

## 5. ④ロケットパンチ：マジンガーZの機構を3段の音にする

資料で確認できたのは**機構**（肘から先が分離／光子力ロケットで飛行／**マッハ2**／誘導可能／
指のジェットで戻る）。⚠️ **効果音の音色そのものは資料で確認できなかった**ので、ここは機構からの
組み立て＝推測を含む。

| 段 | 旧実装 | R31（`rocketPunchFire`） |
|---|---|---|
| ① 肘から先が分離 | 無し | 「ガシャンッ」＝結合が外れる金属音 |
| ② 光子力ロケット点火 | `missileLaunch` の流用 | 腹に来る破裂＋噴射 |
| ③ マッハ2へ加速 | `wireShot` の金属スイープのみ | 4層の上昇スイープ「ギュイィィン！」 |

- **飛来音**：旧実装は射出時に `wireFly` を1回鳴らすだけで、飛んでいる 0.55 秒はずっと無音だった。
  `rocketPunchFly` を拳が近づくほど音程を上げて連打する。
- **命中の衝撃**：ユーザー指示は「音や衝撃も」。音（`rocketPunchHit`＝より低く長い金属爆発）に加えて、
  シェイク460ms/14px・白フラッシュ0.42・**0.11秒のヒットストップ**・二重の衝撃波を足した。
- 引き戻しの一撃音は**命中していないときだけ**鳴らす。命中時に重ねると低音が団子になって、
  かえって軽く聞こえる。

## 7. 途中で踏んだ計測器の欠陥

### (a) ★ボットが一度も攻撃していなかった

最初の3回の計測は**全部無効**だった。合成キーイベントに `keyCode` が無く、Phaser の
`run._jKey.isDown` が一度も true にならない。にもかかわらず結果を「攻撃しているのに減らない」と
読んでいた。`keyCode: 74, which: 74` を足したら **投げ0回→14回**、**HP減少2%→撃破**と正反対になった。

教訓は R21 以来と同じ ——「**比率が桁で違うときはまず計測器を疑う**」。
入力を送る計測器は、**入力が届いたこと自体**（投げ回数が0でないこと）を先に確かめる。

### (b) headless では AudioContext が作られていない

`Sound.startBgm` は `if (!ctx) return;` で即返る。`Sound.init()` を呼ばずに測ったので「鳴った音 0」と
出た。SFX も同じで、**呼び出し回数は数えられるが実際には合成されていない**。
音を測るときは `Sound.init()` を先に呼ぶ。

### (c) 先に倒すとボスを出し直せない

`finishFinal` は本編では `run.endRun(true)` を呼ぶ。段階1でマオウレクスを倒したら段階2で
`practiceSpawn` しても出てこなかった。**倒さない観測を先に**、撃破タイムの計測を最後に置く。

### (d) `Sound` の公開名は `bgm` ではなく `startBgm`

「`sfx` と `bgm` を持つオブジェクト」を探して掴もうとして空振りした。ES モジュールは同一インスタンスが
キャッシュされるので、`await import('/vortex/src/audio/sound.js')` で掴んで `Sound.sfx` を差し替えれば
`boss.js` の呼び出しもそこを通る。

## 9. 申し送り

- **撃破7秒は速すぎないか**は息子さんのFB待ち。ボットは照準のぶれが±26pxしかなく人間より上手いので、
  実プレイはもっとかかるはず。速すぎるなら `hp`（24000）が調整のつまみ。
  ⚠️ **`weak.radius`（27）を戻して難しくするのは筋が悪い** ——「当たったのに0」の再発になる。
- 下半身を弾くようにしたので、分離中の投げが以前より通る。「分離が怖くなくなった」なら、
  下半身の攻撃頻度（`lowerFireSec`）を上げるほうが筋が良い（弾を食わせるのではなく攻めさせる）。
- マジンガーZの**効果音の音色**は資料で確認できていない。実際に聴いてもらって違えば作り直す。
- ミサイルの寿命切れ自爆も爆発として見せるようにしたので、7発斉射のあと**画面に爆発が7つ並ぶ**。
  うるさければ `missileBoom(x, y, false)` 側の粒子とシェイクを落とす。
