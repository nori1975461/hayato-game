# R32 どうくつの作り直し（2026-08-25）

実プレイFB：**「洞窟のアイテムがあまり意味がない思えてならない」**

## 1. 旧版が「意味がない」と言われた理由（実装事実）

旧どうくつは6種。うち画面で確認できるものは実質2種しかなかった。

| 旧アイテム | 効果 | 取った瞬間に画面で分かるか |
| --- | --- | --- |
| ちからのかけら | 攻撃力 +8%（恒久） | ✗ 数字も絵も変わらない |
| はやさのくつ | 移動速度 +6%（恒久） | ✗ 体感差が測定限界以下 |
| いのちのみ | 最大HP +15 | △ バーが少し伸びる |
| まもりのゆびわ | 被ダメージ −5% | ✗ 何も起きない |
| けいけんのたま | XP +120 | △ ゲージが伸びる |
| かいふくのみ | HP回復 | ○ |

- 恒久強化は **やしろ**、武器の合体は **さいだん** が既に担当している。
  どうくつが3つ目の「地味なステータス配り」になっていた。
- 決定的なのは、攻撃力の実体である `heroMult` がこの表に**一度も出てこない**こと。
  攻撃力+8%は主人公の実火力にほぼ乗らない別系統だった。
- 5回引ける枠を全部使っても、やしろ1回に届かない。

## 2. 作り直しの方針

**どうくつ＝「一時的で派手な超能力」の場所**にする。恒久ステータスは一切置かない。
取った瞬間に**見た目が変わる**か**世界の動きが変わる**ものだけにする。

振幅は頻度と逆相関で決める（[[feedback_reward_must_not_saturate]]）。
レア2種は合計12.5%＝1ランに0〜1回なので、振り切ってよい。

### ユーザー指定への対応

- 「**甲子園の砂**。効果は次の弾が渾身の一投になる」→ ①。倍率5.0の根拠は §4。
- 「一定時間無敵になるアイテム。**スターダスト**」→ ③。ただの耐える時間にはせず、
  触れた敵がよろける＝攻めの報酬へ翻訳した（合格基準①へ接続）。
- 「**外見が変化する**アイテムもほしい」→ ④⑤⑥の3種。
- 「他はあなたの発想にまかせる」→ ②⑦⑧⑨。

### 設計上わざと入れた「代償」

ビッグは**当たり判定も大きくなる**。強くなるだけの薬は②被弾の緊張感を殺すため。
ミニは**届く範囲が縮む**。大小を表裏にして、どちらも一長一短にした。

## 4. こうしえんの すな が ×5.0 である根拠

- 実測（R31）：レベル27の投げがマオウレクスのコアへ **1208**。×5 で **6040**。
- マオウレクスの最大HP 24000 に対し **25%**。「ここぞの1発」として体感できる
  最小ラインがおよそ2割で、それを少し超える値に置いた。
- 頻度は6.25%（1ランに0〜1回）。頻度が最低なので振幅は最大にしてよい。
- ⚠️ **溜め量に関係なく必ず最大威力**にした。小5が溜め切りを外した瞬間に
  レアが無駄になるのは、報酬として成立しない。

## 6. 計測器の欠陥を3つ踏んだ（記録）

[[feedback_instrument_must_match_impl]] の再発。数値がおかしい時はまず計測器を疑う。

1. **遠くの的**：ボットは狙いが下手で18秒に3発しか当たらず、倍率が測れなかった。
   測りたいのは命中率ではなく1発のダメージなので、的を主人公の真横に固定した。
2. **`setInterval` でHPを戻す方式が回っていなかった**：実測 **14回/秒**しか回らず、
   その隙間に取り巻き武器の当たりが積もって的が死んだ（観測した最低HP **-144**）。
   さらに、予告を割った直後の一撃は `bossBreakMul` 倍になるので **324×6=1944** が
   1発で入り、maxHp 1800 を一撃で超えていた。
   → ダメージの入口（`dealDamage`）で毎回満タンに戻し、maxHp ごと大きくして解決。
3. **弾の有無を「よろけた敵が場にいるか」で見ていた**：遠くのよろけ敵を数えてしまい
   手元が空になり、掴み損ね＝0.3秒しびれを延々ともらって**投げ回数が0**になっていた。
   → 「掴める距離（50px）にいるか」で見るよう修正。
