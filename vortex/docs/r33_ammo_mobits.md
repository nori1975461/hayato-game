# R33 らいこうだんが一度も出なかった原因と、配る弾を3種へ（2026-08-26）

実プレイFB：**「マオウレクスまでいったのだが、一度も雷光弾が生成されなかった。……昨日の大型改修で、
まさか雷光弾生成の実装がなくなったわけではないか心配」**

## 1. 結論：実装は消えていない。原因は「配り役が仲間にならない」

らいこうだんの経路は R23 のまま生きていた。

- `orbit.js updateAmmo` … ボス戦のあいだ、在庫（通常1発／マオウレクス2発）を配る
- `billiard.js giveAmmo`（旧 `giveBolt`）… スローモーションで手渡し
- `balance.js hero.billiard.bolt` … ボスの最大HPの30%

**回帰確認の実測**：らいこうだん1発でコロガンナー（HP1800）が **552 減＝31%**。仕様どおり。

原因は入手経路だった。自然プレイの実測（EXCEPTIONS=0）：

| 実測 | 旧実装 |
| --- | --- |
| パーティの初期状態 | **2体/2枠＝開始時点で満杯**（スターパピー・ピカビット） |
| 78秒までに拾えず捨てたコア | **43個**（全部コイン50に化けた・仲間になったモビットは0体） |
| 251秒までに捨てたコア | **241個** |
| ビリッコが仲間になった時刻 | **210秒**（3枠目が開く180秒より後） |
| 360秒までのらいこうだん | **2回**（しかも運が悪いとゼロ） |

3枠目が開くのは180秒。R23 で「180秒ちょうどにビリッコのコアを足元へ必ず落とす」保険は入れて
あったが、**その瞬間、地面には常に通常コアが転がっている**（実測 毎秒0.55個）。先に通常コアを
拾うと3枠目が埋まり、ビリッコのコアは10秒で消えてコインに化ける。
＝**運が悪ければ1ランで一度もらいこうだんが出ない。** 息子さんの周がこれ。

## 2. 直したこと

1. **弾配り役（AMMO）だけの特別枠**（`orbit.ammoExtraSlots: 1`）
   AMMO は敵に一切ダメージを与えないので、「公転仲間は最大3人（火力過多の回帰防止）」の
   趣旨には触れない。**戦う仲間は今までどおり3人**のまま、枠の取り合いだけを断つ。
2. **コアを配る時刻を 180秒 → 38秒 へ**（`capture.ammoCoreSec: 38`）
   取り合いが無くなったので、1体目のボス（60秒）に間に合わせられる。

**修正後の実測**：ビリッコは**60秒より前**に仲間入り。最初の特別弾は**90秒まで**に到着。

## 3. ビリッコが配る弾が3種になった

住み分けは「動詞」で分けている。同じ役割の弾を増やすと、3種ある意味が消えるため。

| 弾 | 動詞 | 効果 |
| --- | --- | --- |
| **らいこうだん**（既存） | **当てる** | ボスの最大HPの**30%**を1発。着弾で稲妻が7体へ枝分かれ |
| **スーパーボールだん**（新） | **数える** | 敵から敵へ**最大14回**跳ね返る。跳ねるごとに威力+22%（14回目で約3.9倍）。3回ごとに「◯れんぞく！」。使い切ると半径210pxで締めの炸裂 |
| **ブラックホールだん**（新） | **集める** | 着弾点に1.8秒の穴。半径240pxの雑魚を吸い寄せ、閉じるとき**最大22体を弾（よろけ）に変える**＝弾の量産機 |

- ボス特効は らいこうだん 30% ＞ ブラックホール 10% ＞ スーパーボール 5%（跳ね返りで複数回当たる）。
  **切り札の座は らいこうだんのまま**。
- 配る種類はボスごとに引き直す（シャッフル）。マオウレクス戦は2発なので**必ず違う種類**が来る。
- 手渡しの尺（スロー・稲妻・振りかぶり）は3種で共通。**新しい操作は1つも増やしていない**。
  区別は色と音だけに持たせた（緑＝弾む上昇音／紫＝沈む下降音／黄＝雷鳴）。

### 実測（`scratchpad/cdp-r33-bullets.mjs`・EXCEPTIONS=0・6/6合格）

| 項目 | 実測 |
| --- | --- |
| 3種すべて受け取れる | bolt / superball / blackhole すべて OK |
| スーパーボール | **14回跳ねて 19〜27体撃破**（33体の群れ） |
| ブラックホール | 範囲内12体が**12体とも穴へ寄る**／閉じて**16体が弾になった** |
| らいこうだん（回帰） | ボスHPの **31%** を1発 |

## 4. 計測器と実装の食い違いを2件踏んだ

[[feedback_instrument_must_match_impl]] の再発。両方とも「設定値は正しいのに画面では起きない」型。

1. **ブラックホールの締めに `run.burstStagger` を使っていた**。あれは「**既によろけている敵を
   連鎖で消す**」処理で、健常な敵は削るだけ。実測は**吸い込み7体 → 弾0体**。
   弾を作るのは `enterStagger`（ビリビリホイッスルと同じ経路）。修正後は 16体。
   → 恒久ガード「穴の締めに burstStagger を使っていない」を追加。
2. **スーパーボールが1回で止まっていた**。跳ね返った瞬間に向きを決め打ちしていたので、
   狙った敵が動くぶん（実測 187px先へ0.32秒＝敵は約19px移動）ぎりぎり外れていた。
   毎フレーム少しずつ曲がる（`turnRate: 9 rad/秒`）に変えて、実測 1回 → **14回**。

計測器そのものの欠陥も1件：**「主人公からの距離が縮んだか」で吸い込みを測ってはいけない**。
敵はもともと主人公を追ってくるので、穴が無くても縮む（28体が"寄った"と誤検出した）。
穴の中心からの距離で測る。

## 5. ついでに直したもの

**ハートエンジェル（マシュモの進化）の回復量が上がっていなかった。**
コメントには「回復量が上がる」と書いてあるのに `ovr` が無く、進化しても 3.5秒に2回復のまま。
他の7体の進化はすべて `ovr` を持っている。`ovr: { amount: 3 }`（0.57 → 0.86 HP/秒）にした。
ジェル回復（1.25 HP/秒）は超えないので「少しずつ」は保たれる。
→ 恒久ガード「進化は必ず数値が実際に変わる」を追加。

ビリッコの遠距離フォーム名を「らいこうだん わたし」→「とくべつなたま わたし」に変更（3種になったため）。

## 6. 申し送り

- ビリッコの進化「ライジンガー」は**渡す発数が増えない**（意図的。1発30%×複数は強すぎる）。
  進化しても見た目しか変わらないので、物足りなければ「手渡しが早くなる」等を検討する。
- スーパーボールの跳ね返り回数は群れの密度に依存する。散らばった場では実測3〜4回まで落ちる。
  実プレイで「思ったより跳ねない」と言われたら `bounceRange`(420) を上げるのがつまみ。
- R31/R32 の申し送り（マオウレクス撃破7秒が速すぎないか、どうくつ9種の手触り）は未解決のまま。
