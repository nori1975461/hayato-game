# R34 マオウレクス戦の尺と、エンディングの作り直し（2026-08-26）

実プレイFB（4件）：

> #マオウレクスの音楽が変わってない。元の荘厳さ＋明るさを足した勇ましい曲を依頼したはずだが。
> ミサイルやロケットパンチ？も攻撃音や射出音は修正したか？また、マオウレクスが再合体した際に
> 体の色がメタリックパープルへ変化するはずだが。それもなかった。
> #R31の宿題：マオウレクス撃破7秒は早すぎる。
> #エンディングがしょぼすぎる。もっと派手な演出や音にして。主人公とモビットが一緒に戦っている
> イラストを入れるとかできないか？

## 1. 結論：①②③は別々の不具合ではなく、④の症状だった

実測（`scratchpad/cdp-r34-maou.mjs` ／ `cdp-r34-dps.mjs`・EXCEPTIONS=0）。

| 何を | 修正前の実測 |
| --- | --- |
| 戦闘の長さ（登場イントロ4.4秒込み） | **12.8秒 / 17.6秒**（2回） |
| ボスに入ったダメージの内訳 | **manual（手で投げた玉）100%・たった7発** |
| 1発の最大ダメージ | **5558＝最大HP24000の23%**（4発で92%） |
| ボスが完遂した攻撃 | 12.8秒の回は**0回**（レーザーは分離で中断・ロケットパンチは再合体で中断） |
| ミサイル斉射（本体） | **0回**（攻撃表の4番目なので順番が回ってこない） |
| `rocketPunchFire` | **0回** |
| 再合体・メタリックパープル | **未到達**（2.4秒の合体カットシーンの**0.9秒目**でHPが0になった） |
| BGMが到達した小節 | **4小節目**まで。明るさの要（8小節目のピカルディ終止＝20.0秒）に**永久に届かない** |

つまり「音楽が変わってない」「ミサイルの音は直したのか」「紫にならない」は実装漏れではなく、
**用意したものが再生される前に戦闘が終わっていた**。

さらに実バグが2件あった。

1. **カットシーン中にボスが死ねる**。`weakGate` に無敵判定が無く、合体は原理的に完走できない。
   演出をどれだけ豪華にしても見えない形になっていた。
2. **署名攻撃は「予告を割られる」と中断される**。ボットは予告をほぼ毎回割っており、
   `wireTele` は17回サンプルされたのに `wireShot` へ一度も進んでいなかった。
   ＝ロケットパンチは**発射そのものが起きていない**。

## 2. 直したこと

### ④ 尺（原因）

- **HP 24000 → 120000**。ただし「硬いだけ」にしないための手当てを3つ同時に入れた。
  - **ゲージを3本に区切る**（`gaugeSegments: 3`）。1本ぶち抜くたびに達成が数えられる
    ＝[[feedback_reward_is_countability_not_amplitude]]。区切りは分離(50%)・再合体(33%)の節目と一致する
  - **攻撃の間合いを2割詰める**（`idleSec.betweenAttacks` -20%）。伸びた尺を待ち時間ではなく手数で埋める
  - **特殊弾のボス特効を最終ボスだけ薄める**（`specialBulletMul: 0.34`）。
    R33 で ビリッコ が必ず仲間になるようにしたので、らいこうだん（最大HPの30%）×2発だけで
    6割が消えてしまう。0.34 なら1発10%＝「切り札」の格は保ったまま段の構造を壊さない
- **カットシーン中は無敵**（`weakGate` に `maouIntro / splitCine / mergeCine` を追加）
- **最終ボスは割られても止まらない**（`unstoppable: true`）。
  追撃の窓（×2.4）も装甲片（弾薬供給）も今までどおり渡すので**割る動機は減らない**。
  減るのは「攻撃を中断できる権利」だけ＝ラスボスの格が上がる。
  ⚠️ 1回の予告につき1回まで（`brokeThisAttack`）。連打で窓と弾が無限に湧くのを塞いである

### ② ミサイル／ロケットパンチ

- 音の実装（R31）は**壊れていなかった**。出番が来ていなかっただけ。
- 攻撃表を並べ替え：`['laser','knuckle','wirearm','missile','nova']`
  → **`['missile','wirearm','laser','knuckle','nova']`**。派手な技を先に出す。

### ③ メタリックパープル

- カットシーン無敵で再合体が必ず完走するようになった。
- 加えて**金属光沢**にした。単色 tint で塗るだけだと「紫にした」ではなく「暗くなった」に見えるので、
  本体色 `#a86bff` と内側グロウ `#e0a0ff` のあいだをゆっくり往復させる。
- 予告の点滅の**消灯側**も紫のままにした。null に落とすと素の赤へ戻り、予告のたびに体色が剥がれていた。

### ① BGM（荘厳さの材料には一切手を付けていない）

- **長三和音(C)を3小節目→2小節目へ前倒し**。光が 5.7秒 → **2.5秒**で来る。
  進行は `Am - C - F - G - Am - F - E - A`（和音の顔ぶれは同じ。並びだけ変えた）
- **勇ましさはリズムで作る**（和音を明るくするのではない、が定石）:
  - ファンファーレ（付点の三連ブラス）を1・5・8小節目に
  - ティンパニを「合図」から**行進形**へ（ドーン・ドッ・ドン・ドッ・ドッ）
  - 区切り（4・8小節目）の直前に軍楽のスネアロール
- 84 → **96BPM**（ゆっくりした行進の速さ。battle 150 / boss 172 とはなお別世界）

## 4. ⑤ エンディングの作り直し

R29 の初版は「簡易版でいいので」への最小構成だった。方針を3つ立てて作り直した。

1. **山を作る**。7幕（崩壊 → 光 → **★イラスト** → なかま → 歓声 → 記録 → 締め）にし、
   いちばん高い山（イラストの登場）に演出と音を寄せる。
2. **専用の音**。ここまでの音は全部「戦いの音」なので、祝祭の語彙を新設した：
   `firework`（上がる笛→破裂→散る火の粉の3段）／`endChime`（到達のきらめき）／
   `endFanfare`（凱歌）／`stampHit`（記録が押される音）／`endRubble`（崩れ落ちる残骸）。
3. **★キーイラスト**（`src/data/ending_art.js`・**96×54の描き下ろし**）。
   主人公が渾身の一投を放ち、スターパピー／ピカビット／トゲロンがそれぞれの技で戦い、
   マオウレクスの胸のコアが砕けている1枚絵。6倍（576×324）で全画面に敷き、
   **左から光の帯が走って現れる**幕開けで見せ、そのまま14秒かけてゆっくり寄る。

### イラストの作り方（再生成の手順）

`node vortex/scratchpad/compose-ending-art.mjs` で生成する。手で `ending_art.js` を直さないこと。

- キャラは**イラスト用の新しいポーズ**を描いた（既存スプライトの拡大は不可＝[[feedback_boss_sprite_originality]]）
- PNGを吐いて**実プレイの縮尺（6倍）で**目視確認しながら3回描き直した
  - 試作1：爆発が敵を塗りつぶして「誰と戦っているか分からない」→ 爆発を小さくし顔と角を残す
  - 試作2：主人公を楕円で組んだら**雪だるま**になった → 胴を台形にし、逆光のふちを1px入れる
  - 試作3：空を段でベタ塗りしていて6倍で**水平の縞**が出た → 4×4の整列ディザで混ぜる

### エンディングで踏んだ Phaser の罠

**`Rectangle` は `width` を tween しても見た目が変わらない**（`geom` が更新されないため）。
幕（ワイプ）が開かず、名札の帯も伸びなかった。幕は**同じ幅の黒板を右へ滑らせる**、
帯は `scaleX` で伸ばす。恒久ガードに入れてある。

### エンディングの実測（`scratchpad/cdp-r34-ending.mjs`）

`autotest=1` はエンディングを飛ばす仕様なので、素のまま起動して Ending シーンを直接開き、
10か所の時刻でスクリーンショットを撮って**見える位置で描画されているか**まで見た。

- EXCEPTIONS=0 ／ 全10枚撮影 ／ SPACE スキップで Result へ遷移する
- キーイラストのテクスチャ 96×54 → 表示 576×324（寄りの最大で 605×340・画面内に収まる）
- ⚠️ 途中で見つけた読みにくさを2件直した：
  - なかま紹介の背後にイラストを薄く（0.24）残していたら、**絵の中のモビットと舞台のモビットが
    二重に並んで**どちらが讃えられている子か読めなかった → 幕4〜6は完全に引く
  - タイトルが主人公の顔に乗って読めなかった → 下敷きの帯を敷く

## 5. 恒久ガード（`dev/test-core.js` に49件）

- HP・ゲージ段数・特殊弾倍率・攻撃の並び・`unstoppable` の存在
- `weakGate` がカットシーン中を弾いていること
- 「割られても止まらない」分岐が `endAttackChase` を呼んでいないこと（呼ぶと従来どおり中断される）
- 特殊弾のボス特効**すべて**に個別倍率が掛かっていること（数を突き合わせる）
- BGM：ファンファーレ／行進のティンパニ／スネアロールの存在、長三和音が前半にあること、
  荘厳さの材料（オルガン・鐘）とピカルディ終止を消していないこと
- エンディング：新SFX5種が sound.js に実在し、かつ Ending.js から実際に呼ばれていること
- イラスト：54行×96列・全行の長さが揃う・使用文字が全部パレットにある・
  **主人公とモビット3体と敵が全員描かれている**
- `Rectangle` の `width` を tween していないこと／`Math.random` を呼んでいないこと／
  全画面の白は alpha < 0.5

## 6. 申し送り

- **撃破37.2秒はボットの数字**。ボットは狙点のぶれが±26pxで人間より上手いうえ、
  この計測では死なない（実プレイでは被弾で手が止まる）。息子さんの実時間は**もっと長い**はず。
  長すぎると言われたら、つまみは `hp`（120000）と `specialBulletMul`（0.34）。
- **`unstoppable` は難易度を上げている**。攻撃が中断されなくなったぶん、実プレイの被弾は増える。
  理不尽だと言われたら、まず `idleSec.betweenAttacks` を戻す（-20%した攻撃頻度）のが穏当。
- イラストは固定のキャストで描いてある（主人公＋スターパピー＋ピカビット＋トゲロン）。
  スターパピーとピカビットは初期メンバーなので誰のプレイにも居るが、トゲロンは居ないこともある。
  「連れていない子が絵にいる」が気になると言われたら、なかま紹介側（実際のパーティ）で足りている
  という整理か、パーティ依存の差し替えを検討する。
- R32 の申し送り（どうくつ9種の手触り）は未解決のまま。
