# R34 Wave3 マオウレクス戦BGMの全面作り直しと、ワイヤーアームの砲撃音（2026-08-26）

実プレイFB：

> ナックルウェーブとワイヤーアームは修正されていた。でもワイヤーアームの射出音をもっと派手にして。
> 戦車の砲撃音を参考に。
> マオウレクスの音楽がよくない。全面的に修正して。最終ボスとの闘いにふさわしい圧倒的に盛り上がる
> 音楽を作成して。RPGゲームの「ロマンシング サ・ガⅠ 決戦サルーイン」の楽曲を参考にして。
> 疾走感あふれ、圧倒的な盛り上がり、荘厳でありながら訴えかけるなにかがある。こういう曲を頼む。

## 1. 旧曲では要求に構造的に応えられなかった

R34 の曲は **96BPM・8小節の「行進」**。ここに「疾走感」「圧倒的な盛り上がり」を足すのは無理だった。

| 要求 | 旧曲に足りなかったもの |
| --- | --- |
| 疾走感 | **前へ進む刻みが1つも無い**。ティンパニは「合図」で、主題は4分音符解像度 |
| 圧倒的な盛り上がり | **8小節では山を作る場所が無い**。段が2つしか置けない |
| 訴えかけるなにか | 和声が Am-C-F-G-Am-F-E-A の全音階内で完結していて、外へ出る瞬間が無い |

＝小手先の追加ではなく作り直しが要る、と判断した。

## 2. 参考曲から借りた和声語彙（出典つき）

[ゲーム音楽をソロギターでひたすら弾くブログ](https://guitarblog.net/romancingsaga-saruin/) の採譜による。
**原調はCマイナー**（記事は演奏の都合でBマイナーへ移調）。

| 参考曲（記事のBm） | 原調Cマイナー | 何をしている装置か |
| --- | --- | --- |
| `Bm ×5 → B` | `Cm ×4 → C` | **同主長調へ跳ぶ**。暗いまま押し切らず、同じ主音のまま光が差す |
| `B7 → Em` | `C7 → Fm` | 下属調へのセカンダリドミナント |
| `C#7 → F#7` | `D7 → G7` | ドッペルドミナント→ドミナント。強い推進 |
| `GM7` | `AbM7` | ♭VImaj7。Aメロ/Bメロの広がり |
| `G7` | `Ab7` | ♭VI7。非和声的な押し上げ |
| `C#m7(♭5)` | `Dm7♭5` | 半減七。締めの直前に置くと「訴え」が最も濃くなる |

⚠️ 借りたのは**和声の語彙と配置の作法**であって、旋律ではない。主題はこの曲のために書いている。

「訴えかけるなにか」の正体はいちばん上の**同主長調への跳躍**だと判断した。
短調を4小節保持してから同じ主音の長三和音へ跳ぶので、転調ではなく「同じ場所に光が差す」聞こえ方になる。

## 3. 作り直しの4本柱

### ① 疾走 … 160BPM ＋ 16分音符で刻み続けるベース

テンポだけ上げても曲は走らない。**刻みが背骨**。
拍頭はルート、裏は完全5度、3つ目はオクターブ＝上下に跳ねて前へ転がる。

⚠️ 重ねはオクターブ**上**にした。下（C1=32Hz）へ重ねても子どものノートPCのスピーカーでは
何も鳴らず、疾走の刻みが聞こえないまま終わる。

### ② 山 … 8小節 → 16小節。4小節ずつ4つの段

| 段 | 小節 | 和音 | 何が加わるか |
| --- | --- | --- | --- |
| 決意 | 1-4 | Cm Cm Cm **C** | 刻み＋オルガン＋主題＋鐘 |
| 追撃 | 5-8 | C7 Fm **D7** G7 | ＋キック／スネア／ハイハット（＝段が上がったと耳で分かる） |
| 抒情 | 9-12 | AbM7 AbM7 Cm7 Cm7 | ＋聖歌隊 |
| 頂点 | 13-16 | Ab7 Ab7 **Dm7♭5** G7 | ＋主題の4オクターブ目・鐘を第3音へ・ティンパニ連打 |

**段が上がるたびに音量ではなく声部の数を増やす**。音量だけ上げても飽和して「大きいだけ」になる。

### ③ 訴え … 主題を8分音符解像度で書く

4分音符では160BPMでも走らない。1小節8音。段が上がるほど音域も上げる
（第1段 G4〜G5 → 第4段 Eb5〜**C6**）＝旋律そのものが山を作る。

### ④ 荘厳 … 捨てない

パイプオルガン（全音符＋16フィートの唸り）・聖歌隊・教会の鐘は**全部残した**。
疾走を足すために荘厳を捨てると、ただのバトル曲になって最終ボスの格が消える。

## 4. 実測（`scratchpad/measure-maou-bgm.mjs`）

AudioContext を差し替えて、鳴らそうとした音符を1個ずつ記録して新旧を並べた。

| | 旧（R34） | 新（R34W3） |
| --- | --- | --- |
| テンポ / 小節数 | 96BPM / 8小節 | **160BPM / 16小節** |
| 1周の長さ | 22.86秒 | **24.0秒**（倍の小節数を1割長いだけで走り切る） |
| 音符の密度 | 11.0 音符/秒 | **49.6 音符/秒（4.5倍）** |
| 打楽器の密度 | 0.89 打/秒 | **7.75 打/秒（8.7倍）** |
| 小節ごとの根音 | A F C G A F E A | **C C C C / C F D G / Ab Ab C C / Ab Ab D G** |
| 最高音 | 3520Hz | **4186Hz（C6）** |
| 光（長三和音）が来る時刻 | 2.50秒 | **4.5秒**（4小節目。参考曲と同じ「4小節保持してから跳ぶ」作法） |

戦闘は実測37.9秒なので、**頂点の段（18.0〜24.0秒）を必ず1回通る**。

## 5. ワイヤーアーム：戦車の砲撃音

参考にしたのは実物の**大口径砲の砲口爆風に関する測定研究**（下記出典）。

1. 砲口爆風は装薬室と大気の**圧力差**で生じる衝撃波＝立ち上がりが極端に速い（ミリ秒級）
2. 推進ガスが**超音速**で砲身を抜けるため、高強度のインパルス音になる
3. 戦車砲（HEAT弾）の初速は**マッハ3.5**。弾体そのものが**N波**（鋭いクラック）を引く
4. 砲声は「一発の破裂」ではなく、そのあと周囲に**轟いて減衰する長い尾**を持つ

⚠️ 録音そのものの音色資料は確認できていないので、上の1〜4という**機構**から組み立てている（推測を含む）。

旧実装（`rocketPunchFire`）は「ガシャン→点火→スイープ」でロケットの語彙だけだった。
足りなかったのは **極端に速い立ち上がり**（attack 0.5ms）と **長い反響**（0.9秒）＝これが「砲撃」の正体。

`wireCannon()` の構成：①撃発 ②砲口爆風（極短・広帯域） ③N波クラック ④長い反響 ⑤砲身の後座。
ロケットの点火は **0.45倍に薄めて**後ろへ重ねた（両方を全開で鳴らすと潰れて、かえって小さく聞こえる）。
揺れも 340→**430**、閃光 0.38→**0.44** に上げてある。

## 7. 恒久ガード（`dev/test-core.js` に37件・全497件）

疾走（BPM≥150・16小節・16分刻みの存在・刻みが拍内で音高を変える）／
山（4小節ごとの段・段ごとに声部が増える3か所）／
訴え（同主長調へ跳ぶ小節が前半・半減七・ドッペルドミナント・♭VImaj7・♭VI7 が進行にある・**出典が書き残してある**）／
主題が8分音符解像度（データと再生側の両方）／
荘厳の材料4つを残している／疾走のビート4種／
砲撃音（ミリ秒級の立ち上がり・長い反響・広帯域・薄めて重ねる）。

⚠️ R31/R34 の「80〜105BPM＝重さを保つ」「締めはピカルディ終止」は**撤回**した。
遅いテンポでは「疾走感」に構造的に応えられないため。守るべき意図（暗いまま押し切らない／
荘厳の材料を捨てない）は新しいガードで引き続き見張っている。

## 8. 申し送り

- **曲の良し悪しは聞いてもらうのが最速**。タイトルで `T` → キー `4`「マオウレクスとたたかう」で
  この曲がそのまま流れる。まずタイトル左下が **`v20260826-4`** か確認（違えば `Ctrl+Shift+R`）
- 160BPM は battle(150) / boss(172) の**あいだ**。テンポでは区別がつかないので、
  楽器（オルガン・聖歌隊・鐘）と和声で区別している。「普通の戦闘曲に聞こえる」と言われたら
  テンポではなく**オルガンと鐘を厚くする**のが正しい方向
- 1周24.0秒・戦闘37.9秒なので、頂点の段は**1回しか通らない**。
  「頂点をもっと聞きたい」と言われたら段の並びを変える（例：頂点を9-12小節へ前倒し）
- R34/R34W2/R32 の申し送りは未解決のまま
