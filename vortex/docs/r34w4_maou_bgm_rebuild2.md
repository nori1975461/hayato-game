# R34 Wave4 マオウレクス戦BGMの再作曲と、命中音を鈍器へ（2026-08-26）

実プレイFB：

> ワイヤーアームが主人公に当たったときの豆鉄砲のような空気の抜けた音を修正して。
> 鈍器で殴ったような派手な効果音にして。
> マオウレクスのBGMがよくない！ロマンシングサガの神曲といわれる曲を研究して。
> もっとアップテンポで迫力のある曲にして。徹底的に調査し全知全能をかけて作成して。

## 1. 調査でいちばん大きかった知見

**「アップテンポにする」だけでは迫力は出ない。**
参考曲が速く感じるのはテンポではなく、**和音の動く速さ（ハーモニックリズム）**と**七の連鎖**による。

### 何が「神曲」と呼ばれているか

サガシリーズのバトル曲で神曲と呼ばれるのは主に **四魔貴族バトル2（ロマサガ3）** と
**七英雄バトル（ロマサガ2）**。七英雄バトルはスクウェア・エニックス公式の人気投票で2位。
四魔貴族バトル1／2 と七英雄バトルは「毎回票が割れる」ほど人気を二分している。

### 四魔貴族バトル2 の公式に語られている特徴

- **高速ロック**で、途中に**劇的な転調**がある
- **ツーバス（ダブルバスドラム）＋ディストーションギター**。当時のゲーム音楽では珍しい編成
- 作曲者本人が「**初めてエレキギターを使った曲**」「定型から抜け出せた曲」と述べている
- イントロだけで1分を超え、そこに1〜10日かけた

### 四魔貴族バトル1 の採譜から読み取れた作法（原調E♭マイナー／記事はAmへ移調）

イントロ: `Am7 | G7 | C7 A7(♭9) | Dm7 | G7 Am7 | G7 C7 | F7 B7 | E7 | …`
Aメロ: `Am B7 | Em C | F E7 | Am E7(onG♯) | … | Bm7(♭5) | E7sus4 | F♯dim7 | E7`

| 作法 | 何をしているか |
| --- | --- |
| **1小節に2つの和音** | ハーモニックリズムが速い。これが「速く聞こえる」の本体 |
| **セブンスの連鎖** | `Am7 G7 C7 A7♭9 Dm7`。常に解決したがっているので前へ転がる |
| **4度上行の連鎖** | `F7 → B7 → E7` |
| **ディミニッシュのパッシング** | `Ddim7 / F♯dim7` |
| **転回形でベースが半音で動く** | `E7(onG♯)` |
| **フラットナインス** | `A7(♭9)` ＝濃い緊張 |

### R34W3（前回作った曲）に無かったもの＝まさにこの5つ

前回は 160BPM・**1小節1和音**・三和音中心だった。テンポを上げても
「和音が1小節動かない」ままでは迫力は出ない、というのが今回の結論。

## 2. 作り直した曲（Cマイナー・184BPM・16小節・**半小節ごとに和音が動く**）

```
段1（突撃）  Cm7  Cm7 | Bb7  Bb7 | Eb7  C7♭9 | Fm7  Fm7
段2（追撃）  Bb7  Cm7 | Bb7  Eb7 | Ab7  D7   | G7   G7      ← 4度上行の連鎖
段3（主題）  Cm   D7  | Gm   Eb  | Ab   G7   | Cm   G7      ← 1小節2和音で畳みかける
段4（頂点）  C#m  D#7 | G#m  E   | A    G#7  | G7   G7      ← ★半音上へ転調 → 滑り落ちて元調へ
```

- **32要素の和音配列**（16小節×2）。再生側も `bar * 2 + (inBar >= 8 ? 1 : 0)` で半小節ごとに引く
- **七の和音が主役**（Cm7 / Bb7 / Eb7 / C7♭9 / Fm7 / Ab7 / D7 / G7）
- **段4で半音上へ転調**し、最後の `G#7 → G7` の半音すべりで元調へ戻る＝「劇的な転調」
- 主題は8分音符解像度。段が上がるほど音域も上げる（第1段 F4〜Eb5 → 第4段 C#5〜**C6**）

⚠️ 借りたのは**作法**であって旋律ではない。主題はこの曲のために書いている。

## 3. 編曲（迫力の半分は音色）

| 声部 | 何のために |
| --- | --- |
| **ツーバス** | 8分でキックを踏み続ける。四魔貴族バトル2の要 |
| **パワーコードの刻み** | ルート＋5度を8分で。和音が動くたびに手応えが変わる＝ロックの迫力 |
| **ディストーション風リード** | デチューン3枚重ね＋**3倍音・5倍音**。歪みの正体は奇数倍音。単音のsawtoothでは細い |
| **クラッシュシンバル** | 段の頭。段が変わったことを一撃で知らせる |
| **ドラムのフィルイン** | 段の変わり目に雪崩れ込む |
| オルガン／聖歌隊／鐘 | **残した**。疾走と迫力のために荘厳を捨てるとただのバトル曲になる |

## 6. 命中音「豆鉄砲のような空気の抜けた音」

**原因は特定できた。長くて深い下降スイープ。**

旧実装は `320Hz → 16Hz` を **0.62秒**かけて下げていた。これは物理的に
「ひゅ〜」と抜けていく笛の作り方そのもの。さらに **0.46秒の中域ヒス**が乗って「シュー」を足していた。

鈍器の一撃は逆の性質を持つ：

1. 立ち上がりが **0.4ms級**
2. 基音は**ほぼ固定**（下げても半分まで）
3. 尾が**短い**
4. **打撃面の「ゴッ」という固定音程の胴鳴り**が要る（スイープでは絶対に出ない）

作り直した `rocketPunchHit()` は ①芯（112→64Hz・0.16秒） ②固定音程の胴鳴り3声（196/262/147Hz）
③極短・広帯域の一撃クラック（12ms） ④鉄と鉄の高域 ⑤短く低い尾。

**回帰防止のガードを式で入れた**：命中音の中に
「dur ≥ 0.35秒 かつ freq/freqEnd ≥ 4倍」のスイープがあると落ちる／
0.3秒以上のノイズの尾があると落ちる。

## 7. 恒久ガード（`dev/test-core.js` に47件・全514件）

和音が小節数の2倍あること・再生側も半小節ごとに引いていること／七の連鎖7種／C7♭9／
転調が最後の段にあり元調へ戻ること／調査した参考曲名が書き残してあること／
ツーバスと編曲3種／デチューン3枚と奇数倍音／荘厳の材料4つ／
3つの曲が SONGS に実在し、れんしゅうじょうから B キーで切り替えられ、
ボスを出し直しても選んだ編曲のままになること／**命中音の下降スイープ禁止**。

## 9. 申し送り

- **3つのうちどれが良いかを聞いてほしい**。タイトル `T` → `4` → **`B` で巡回**（画面左上に名前が出る）。
  「どれも違う」場合は、次に効くのは**テンポではなく和音の動かし方**（例：段3を1小節4和音にする）
- ②ちょうこうそく(208) は battle(150)/boss(172) より速いので、区別は付くが慌ただしい可能性がある
- ディストーションは奇数倍音の付加で近似しているだけで、本物の歪み（波形クリップ）ではない。
  もっと歪ませたい場合は WaveShaperNode の導入が要る（未実装・音量設計をやり直す必要あり）
- R34W3 以前の申し送りは未解決のまま
