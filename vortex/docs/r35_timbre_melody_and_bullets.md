# R35 音色から作り直す／主題を歌にする／マオウレクスの弾（2026-08-27）

実プレイFB：

> 曲はどれも違う。つくりなおして。
> ワイヤーアーム直撃の効果音をもっとガツンという激しい音にして。鈍器で頭を思いっきりなぐったような音。極端すぎるくらいでちょうど良い。

## 1. 曲：3回の不採用から絞り込めたこと

| | 何を変えたか | 結果 |
| --- | --- | --- |
| R34 | 勇ましい行進（96BPM） | よくない |
| R34W3 | 決戦サルーイン参考・160BPM・16小節 | よくない |
| R34W4 | 神曲研究・184BPM・和音32個・七の連鎖・転調・編曲3種（168/184/208） | **どれも違う** |

**テンポは軸ではなかった。** 168 / 184 / 208 を並べて聞いてもらって3つとも「違う」。
**和声も軸ではなかった。** 和音を倍の速さで動かし、七の連鎖も転調も入れて届かなかった。

消去法で残るのは **①旋律 ②音色**。そしてこの2つは、3回とも本気で触っていなかった。

### ①旋律：音符を増やしたのが逆効果だった

R34W4 は「アップテンポで迫力」に対して **音符を2倍（49.6→99.6 音符/秒）に増やした**。
8分音符で全部の枡を埋めると、それは旋律ではなく**分散和音の壁**になる。
参考曲が耳に残るのは音が多いからではなく、**長い音と休符があって歌えるから**。

- 音符に**長さの違い**を持たせた（`H` ＝タイで前の音を伸ばす／`-1` ＝休符）。
  R34W4 までは**全部の音が同じ長さ（1.9枡）**で鳴っていた＝長い音も休符も一つも無い構造だった。
- 128枡中 **66音**まで減らし、伸ばす音を62個入れた。1小節3〜5音。
- 2小節の呼びかけ＋2小節の応え。段が上がるごとに同じ動機を高い音域で繰り返す。
  最高音は段4の **C#6**（転調した頂点）。
- 伴奏（16分ベース＋ツーバス）はそのままなので疾走感は落ちない。

### ②音色：歪みが本物ではなかった

旧実装は「sawtooth を3枚デチューン＋3倍音・5倍音を足す」で歪みを近似していた。
**足し算では歪まない。** 倍音の比率が入力の大きさで変わらないからで、
歪みの本体は非線形＝**大きい入力ほど潰れること**。それは波形を折らないと出せない。

- **WaveShaperNode**（arctan型ソフトクリップ）を導入。実ブラウザで2個生成されることを実測済み。
- **フィードバック・ディレイ**（111ms / 173ms・減衰0.36・高域から先に減る）で残響。
  「荘厳」は残響が作る。今までBGMは全声部が完全にドライで、音が床に落ちていた。
- ⚠️ drive は上げすぎると逆効果。WebAudio のカーブは入力 ±1 の外を端の値へ丸めるので、
  入力が常に1を超えると出力が定数に張り付く＝**強弱も音程感も消えたただのブザー**になる。
  BGM側は同時に鳴る声部の合計が 0.2〜0.37 なので drive 3.2（＝0.64〜1.18）に置いた。

### 作法5つを全部使い切った

四魔貴族バトル1 の採譜から読み取れた作法のうち、R34W4 では3つしか使えていなかった。

| 作法 | いつ入れたか |
| --- | --- |
| 1小節に2つの和音 | R34W4 |
| セブンスの連鎖 | R34W4 |
| 4度上行の連鎖（Ab7→D7→G7） | R34W4 |
| **ディミニッシュのパッシング（F#dim7）** | **★R35** |
| **転回形でベースが半音で動く（G7(onB)→Cm）** | **★R35** |

```
段1（名乗り）  Cm7 Cm7 | Bb7 Bb7 | Eb7 C7♭9 | Fm7 Fm7
段2（追撃）    Bb7 Cm7 | Bb7 Eb7 | Ab7 D7   | F#dim7 G7   ← ディミニッシュのパッシング
段3（主題）    Cm  D7  | Gm  Eb  | Ab  G7/B | Cm  G7      ← 転回形でベースが半音（B→C）
段4（頂点）    C#m D#7 | G#m E   | A   G#7  | G7  G7      ← ★半音上へ転調 → 元調へ
```

### ★聞き比べを「実験」として設計した

R34W4 はテンポとドラムの重さだけを変えた3つを並べて、3つとも外した。
今回は**作曲は共通のまま、編成そのものを変えた3つ**にした。
どれが選ばれるかで「音色が原因だったのか」が分かる。

| | 編成 | BPM | 実測（32小節） |
| --- | --- | --- | --- |
| ① ギター（ひずみ） | WaveShaperで潰したギター＋ツーバス | 178 | 音符3078・のこぎり1782 / 矩形612 |
| ② オーケストラ | ブラス／弦のトレモロ／合唱／ティンパニ | 168 | 音符2882・のこぎり1135 / **三角1095** |
| ③ シンセ（しっそう） | 矩形波＋16分アルペジオ | 190 | 音符3136・**矩形1904**・打楽器810 |

波形の内訳が3つで別物になっている＝テンポ違いではなく本当に編成が違う。
れんしゅうじょう（タイトルで `T` → `4`）の **`B` キー**で巡回できる。

⚠️ 計測スクリプトは AudioContext のスタブなので **WaveShaper が作り出す倍音は測れない**。
「最高音 5233→2218Hz」は乾いた声部だけの値で、実際の出力はこれより上まで伸びる。

## 2. ワイヤーアーム直撃音「もっとガツン。極端すぎるくらいでちょうど良い」

R34W4 で「豆鉄砲（＝長い下降スイープ）」は消したが、そこで止まっていた＝**抜けは直ったが痛くない**。
強打を強打に聞かせるのに要るものが3つ、まだ入っていなかった。

| | 何をしたか | なぜ |
| --- | --- | --- |
| ⓐ **二段構え** | 0ms「ガッ」→ **18ms** →「ツン」 | 重さは一発の大きさではなく**2つの音の間**が作る。一点に重ねると大きいだけの「ドン」になる |
| ⓑ **本物の歪み** | 命中音を sfxDistBus（drive 5.0・k 25）へ通す | 潰れた波形＝出せる限界を超えた音。「暴力的」の正体 |
| ⓒ **BGMを沈める** | 0.1秒だけ bgmGain を 26% へ（サイドチェイン） | 周りが引くと同じ音量でも一撃が重くなる。**音量を上げるより効き、耳に痛くない** |

- 骨・木の胴鳴りは固定音程3つを**わざと濁らせて**重ねる（協和させると「楽器」になる）
- 金属バットの鳴きは**非整数倍音 1 : 2.76 : 5.40**（鉄板・棒を叩いたときの実際の比）
- 最大ゲイン 0.52 → **0.94**
- 画面側も：ヒットストップ 0.11→**0.17秒**、シェイク 460/14→**560/22**、白フラッシュ 0.42→0.48

⚠️ R34W4 の回帰防止（0.35秒以上×4倍以上の下降スイープ禁止／0.3秒以上のノイズ尾禁止）は
そのまま守っている。ガードは式で判定しているので、激しくする過程で戻ることはない。

## 3. マオウレクスの弾「小さな破砕片のような弾が全くイケてない。スピードも遅い」

**指摘どおりどころか、速度が逆転していた。**

| | 弾速(px/秒) | 主人公(148)比 |
| --- | --- | --- |
| 序盤の雑魚スナイパー | 330 | 2.23倍 |
| マオウレクス missile | 480 | 3.24倍 |
| マオウレクス knuckle | 320 | 2.16倍 |
| **マオウレクス vulcan（旧）** | **150** | **1.01倍** |
| **マオウレクス nova（旧）** | **116** | **0.78倍＝歩いて追い抜ける** |

見た目も radius 4（16×10px）で、**radius 82 の巨体から砂粒が出ている**構図だった。

### 直したこと

| | 旧 | 新 |
| --- | --- | --- |
| nova 弾速 | 116 | **265**（主人公の1.79倍） |
| vulcan 弾速 | 150 | **340**（雑魚スナイパー330と同格） |
| ring 弾速 | 150 | **240** |
| 弾の半径 | 4（16×10px） | **8 / 7**（30×16px の彗星） |
| 見た目 | boss_bolt（鏃形の小片） | **boss_comet**（新規・後端が尖り先端が丸い彗星＋白熱の芯＋尾） |

- **理不尽にしていない根拠**：ノヴァは14発の全方位なので隣接弾の角度差は 25.7°＝距離200pxで隙間89px。
  主人公(半径7)＋弾の芯(5)＝12px あれば通れる。むしろ速くすると波の間隔が
  18.6px→42px に広がって**縫いやすくなる**。予告1.1秒は据え置き、ダメージは 20→18 に下げた。
- **当たり判定は絵の外形ではなく白熱の芯（5px）に合わせた**。
  30×16 の外形で当てると「かすってもいないのに当たった」になる（[[feedback_one_hit_one_circle]]）。
- 火の粉は**1フレーム合計3個までの予算制**。ノヴァは1回で70発飛ぶので、
  1発ずつ尾を出すと毎秒数千個のスプライトになって確実に処理落ちする。

## 4. 実測（`scratchpad/cdp-r35-verify.mjs`・EXCEPTIONS=0）

```
① モジュール取得 27本 / うち ?v= 付き 27本 ／ タイトルの版表示 "v20260827-1"
② 実ブラウザで生成: WaveShaperNode 2個 / DelayNode 2個
   焼かれたカーブ長 2048 / 入力2倍→出力 1.289倍（2.0未満＝本当に潰れている）
   命中音のBGMダック: 0.78 → 0.203 → 0.78（必ず戻る）
③ れんしゅうじょうのBGM: ["battle","maou","maou","maouOrch","maouSynth","maou"]
④ 弾の実測: {"missile":1064,"tomahawk":877,"comet":7111} / 同時最大69発
   彗星弾の実速度 265 px/秒（旧116・主人公148）
⑤ ワイヤーアーム直撃音 rocketPunchHit: 4回
⑥ 実FPS 平均53.9 / 最低40（変更前は平均58.2 / 最低41）
```

⚠️ **⑤で1回つまずいた**。最初の2回の実測は直撃音が **0回**で、
「作った音が一度も鳴っていない」を確かめられなかった（R34 と同じ落とし穴）。
原因は計測ボットではなく**ゲーム側の至近距離の死角**だった：
拳は肩（ボス中心から左右へ 11×9.6＝**±105px**）から出るのに狙う向きはボス中心から見た角度なので、
主人公が110pxまで寄っていると必要な旋回が atan(105/110)≒**44°**、旋回上限は 54°/秒×0.55秒＝**約30°**で
**構造的に届かない**。予告のあいだに260pxまで離れるようボットを直して4回の直撃を観測した。

⚠️ **FPS は平均で 58.2→53.9（-7%）落ちている**。最低フレームレートは 41→40 でほぼ同じ。
弾が大きくなり発光も広がったぶんの塗り面積が原因で、しかもこの計測は `--disable-gpu` の
ヘッドレス（CPU描画）なので実機より不利に出る。ただし**測って落ちたことは事実**なので記録しておく。

## 5. 恒久ガード（`dev/test-core.js` に60件・全564件）

歪みカーブが**本当に非線形か**を式から数値で検証（入力2倍→出力1.56倍）／
常時フルクリップになっていないこと／主題の音数と伸ばす音の数／再生側もタイを数えていること／
F#dim7 と G7(onB) がデータ上も転回形になっていること／編成3種が別の楽器を鳴らしていること／
命中音の二段構え・非整数倍音・BGMダックが元に戻ること・最大ゲインが前より大きいこと／
弾速が主人公と雑魚の両方を上回ること・速くしたぶんダメージを上げていないこと／
彗星テクスチャが専用であること・火の粉の予算制・当たり判定が芯に合っていること。

⚠️ **2件を明示的に撤回した**（旧設計を守るガードが新設計を妨げるため）：
凱歌のファンファーレ（音符を増やす方向に働いていた／段の区切りはクラッシュとフィルインで守り直し）と、
「3倍音・5倍音で歪みを近似する」（足し算では歪まないという今回の知見そのもの）。

## 6. 申し送り

- **①②③のどれが良いかを聞いてほしい**。タイトル `T` → `4` → **`B` で巡回**（左上に名前が出る）。
  今回は編成そのものを変えてあるので、選ばれた1つが「音色が原因だった」の答えになる。
  **3つとも違う場合、次は旋律そのもの**（今回の主題が好みでない）＝
  「どんな感じ？」を言葉ではなく**既存のどれに近いか**で示してもらうのが早い。
- ワイヤーアームの**至近距離の死角**（上記⑤）は未修正。仕様として残すか直すかは要判断。
- FPS -7%（上記）。実機で重く感じるようなら彗星のグロウ（現在 8.4r × 3.2r）を先に削る。
- R32〜R34W4 の申し送りは未解決のまま。
